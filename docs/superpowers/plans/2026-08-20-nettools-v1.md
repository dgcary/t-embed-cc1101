# NetTools v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a T-Embed CC1101 Plus NetTools menu containing Network Info, Ping, Traceroute, Host Discovery, and a bounded-concurrency TCP Port Scanner.

**Architecture:** Keep Bruce as the UI/connection-management layer and add a small `src/modules/nettools` diagnostic layer. A reusable raw-ICMP session supplies Ping, Traceroute, and Discovery; a separate non-blocking TCP scanner supplies common/range scanning. `NetToolsMenu` owns only user input, progress, and display.

**Tech Stack:** C++/Arduino ESP32, lwIP raw/TCP sockets, Bruce `MenuItemInterface`, `ScrollableTextArea`, PlatformIO.

**Spec:** `docs/superpowers/specs/2026-08-20-nettools-v1-design.md`

## Global Constraints

- Target environment: `lilygo-t-embed-cc1101`.
- Register NetTools only under `T_EMBED_1101`.
- Do not modify the immutable `baseline/bruce-1.16.1` branch.
- Do not modify existing WiFi/RF/BLE/NFC production modules for NetTools v1.
- No new external library unless compilation proves unavoidable.
- Diagnostic only: no deauth, spoof, flooding, credential attacks, or remote state modification.
- Maximum 8 simultaneous TCP scan sockets.
- Host Discovery refuses derived subnets with more than 1024 usable hosts.
- Codex does not develop or compile; Codex only flashes, monitors serial, and performs physical tests after ChatGPT build PASS.

### Task 2: Shared network utilities and raw ICMP engine

**Files:**
- Create: `src/modules/nettools/NetToolsUtils.h`
- Create: `src/modules/nettools/NetToolsUtils.cpp`
- Create: `src/modules/nettools/IcmpProbe.h`
- Create: `src/modules/nettools/IcmpProbe.cpp`
- Test: `tools/tests/test_nettools_contract.py`

**Interfaces:**
- Produces:

```cpp
bool resolveNetToolsTarget(const String &host, IPAddress &address);
String netToolsServiceName(uint16_t port);
uint32_t ipToHostOrder(const IPAddress &ip);
IPAddress hostOrderToIp(uint32_t value);

struct IcmpProbeResult {
    bool success = false;
    bool reachedTarget = false;
    bool timeExceeded = false;
    IPAddress responder;
    uint32_t rttUs = 0;
    uint8_t replyTtl = 0;
};

class IcmpProbeSession {
public:
    IcmpProbeSession();
    ~IcmpProbeSession();
    bool begin();
    bool isReady() const;
    IcmpProbeResult probe(const IPAddress &target, uint8_t ttl, uint16_t sequence, uint32_t timeoutMs);
};
```

- [ ] **Step 1: Implement target resolution and IP conversion helpers**

`resolveNetToolsTarget()` first accepts a dotted IPv4 literal with `IPAddress::fromString`; otherwise calls `WiFi.hostByName`. Empty targets fail.

- [ ] **Step 2: Implement ICMP checksum and RAII raw socket**

`IcmpProbeSession::begin()` creates:

```cpp
lwip_socket(AF_INET, SOCK_RAW, IPPROTO_ICMP)
```

The constructor initializes `socketFd = -1`; destructor calls `lwip_close(socketFd)` only when valid. Identifier is randomized once per session using `esp_random()`.

- [ ] **Step 3: Implement one ICMP probe**

For each probe:

1. Set `IP_TTL` with `lwip_setsockopt`.
2. Build an 8-byte ICMP Echo header plus a small deterministic payload.
3. Compute the ICMP checksum.
4. `lwip_sendto()` target.
5. Wait with `lwip_select()` until timeout.
6. Parse outer IPv4 IHL and ICMP.
7. Accept Echo Reply only when identifier/sequence match.
8. Accept Time Exceeded only when the quoted inner ICMP identifier/sequence match.
9. Return responder and RTT.

Expected: ICMP assertions pass; menu/scanner assertions remain RED until later tasks.

### Task 3: Bounded-concurrency TCP port scanner

**Files:**
- Create: `src/modules/nettools/PortScanner.h`
- Create: `src/modules/nettools/PortScanner.cpp`
- Test: `tools/tests/test_nettools_contract.py`

**Interfaces:**
- Consumes: target IP and `netToolsServiceName()`.
- Produces:

```cpp
struct PortScanResult {
    uint16_t port = 0;
    String service;
};

using PortScanProgress = std::function<bool(uint32_t scanned, uint32_t total)>;

std::vector<PortScanResult> scanTcpPorts(
    const IPAddress &target,
    uint16_t startPort,
    uint16_t endPort,
    uint32_t timeoutMs,
    PortScanProgress progress
);

std::vector<PortScanResult> scanCommonTcpPorts(
    const IPAddress &target,
    uint32_t timeoutMs,
    PortScanProgress progress
);
```

- [ ] **Step 1: Implement the fixed common-port list**

Use a curated TCP list including at least:

```text
21,22,23,25,53,80,110,135,139,143,179,389,443,445,465,514,515,554,587,631,636,
873,902,993,995,1433,1521,1723,1883,2049,2375,2376,3306,3389,5432,5900,5985,5986,
6379,6443,8000,8080,8443,9000,9100,9200,10000,27017
```

- [ ] **Step 2: Implement one non-blocking batch**

Define:

```cpp
static constexpr size_t MAX_CONCURRENT_SOCKETS = 8;
```

For each batch:

1. create TCP sockets;
2. set `O_NONBLOCK` with `lwip_fcntl`;
3. call `lwip_connect`;
4. collect immediate successes and `EINPROGRESS` sockets;
5. call `lwip_select()` on writable sockets with the batch timeout;
6. call `lwip_getsockopt(... SO_ERROR ...)`;
7. record only `SO_ERROR == 0` as open;
8. close every socket with `lwip_close` on every path.

- [ ] **Step 3: Add cancellation/progress**

Invoke the progress callback after each batch. If it returns `false`, close current sockets and stop cleanly.

- [ ] **Step 4: Run the contract test**

Expected: scanner assertions pass; menu assertions remain RED.

- [ ] **Step 5: Commit**

```bash

git commit -m "feat: add bounded TCP port scanner"
```

**Files:**

- Produces: `NetToolsMenu : public MenuItemInterface` with `optionsMenu()` and `drawIcon()`.

- [ ] **Step 1: Add `ensureConnected()` and Network Info**

If not connected, call Bruce's existing Wi-Fi connection flow. Network Info renders SSID, BSSID, IP, mask, gateway, DNS1/2, station MAC, RSSI, and channel into a `ScrollableTextArea`.

- [ ] **Step 2: Add Ping UI**

Prompt for host/IP. Resolve target. Open one `IcmpProbeSession`. Send four probes at TTL 64 with 1000 ms timeout and 250 ms interval. Add reply/timeout lines and final transmitted/received/loss/min/avg/max summary.

- [ ] **Step 3: Add Traceroute UI**

Prompt for host/IP. Resolve target. Probe TTL 1..20, one probe per hop, 1000 ms each. Display hop IP + RTT or `*`; stop on Echo Reply. Back cancels between hops.

- [ ] **Step 4: Add Host Discovery UI**

Define:

```cpp
static constexpr uint32_t MAX_DISCOVERY_HOSTS = 1024;
```

Compute network/broadcast from `WiFi.localIP()` and `WiFi.subnetMask()`. Refuse if usable addresses exceed 1024. Probe each usable host except self using 100 ms timeout. Display progress and final responsive-host list.

- [ ] **Step 5: Add Port Scanner UI**

Prompt target, then mode menu:

```text
Common Ports
Port Range
Back
```

For range mode, validate 1..65535 and start <= end. Full-range is allowed and displays a warning before scanning. Progress callback checks `EscPress`; final `ScrollableTextArea` lists open ports and elapsed time.

- [ ] **Step 6: Add NetTools submenu and icon**

Submenu:

```text
Network Info
Ping
Traceroute
Host Discovery
Port Scanner
Back
```

Use an icon representing connected network nodes. No new font/assets.
